# 📊 Netflix Dashboard (Excel)

## 📌 Overview

This project is an interactive Netflix Dashboard created in Microsoft Excel to analyze Netflix content using charts, KPIs, slicers, and data visualization techniques.

---

## 📈 Features

- Total Movies & TV Shows
- Content by Rating
- Release Year Analysis
- Genre Distribution
- Country-wise Analysis
- Interactive Slicers
- KPI Cards
- Dynamic Charts

---

## 🛠 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning
